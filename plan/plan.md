# Pubblicazione del codice del sito su GitHub (repository pubblico)

Il codice completo del sito Estetica Beauty & Care va salvato su GitHub, sull'account personale della titolare, in un repository visibile a tutti.
Prima di salvarlo, le password e le chiavi segrete vengono tolte dal codice, così nessuno può usarle.

## Per chi è
- La titolare del centro, che vuole avere una copia del codice sul proprio account.
- Il tecnico di WebDev Innovations, che potrà consultare il codice o lavorarci in futuro.

## Cosa si ottiene
- Un repository pubblico su GitHub con tutto il codice del sito: le pagine, il pannello admin, le traduzioni nelle 4 lingue, le promo e l'evento.
- Nessuna password o chiave segreta visibile nel repository: password admin, chiave di sicurezza degli accessi, chiave per il salvataggio delle immagini, file con le credenziali di prova.
- Il sito online (esteticabeautycare.com) continua a funzionare come oggi: cambia solo dove viene conservato il codice.

## Come funziona per la titolare
1. Approva questo piano.
2. Le password e le chiavi vengono escluse da quello che va su GitHub.
3. Nella chat preme il pulsante **"Save to GitHub"** (in basso, vicino al campo di scrittura).
4. Collega il proprio account GitHub, se non l'ha già fatto, e sceglie un nome per il repository, per esempio `esteticabeautycare`.
5. Conferma il salvataggio: il codice compare sul suo account GitHub.
6. Per le modifiche future basta premere di nuovo "Save to GitHub".

## Aspetto
Nessun cambiamento visibile sul sito: grafica, testi, promo ed evento restano identici.

## Fasi
1. **Fase 1 (ora): messa in sicurezza e salvataggio.** Le password e le chiavi vengono escluse dal repository e il codice viene salvato con "Save to GitHub". Viene aggiunta anche una breve pagina di presentazione del repository: cos'è il sito e chi lo gestisce (WebDev Innovations).
2. **Fase 2: cambio password admin.** La password del pannello admin e la chiave di sicurezza degli accessi vengono sostituite con valori nuovi, poi il sito viene ripubblicato. Così, anche se una vecchia versione fosse finita online, quei valori non funzionerebbero più.
3. **Fase 3: accesso del tecnico.** La titolare invita il tecnico di WebDev Innovations come collaboratore del repository, così può proporre modifiche.

## Assunzioni
- Il salvataggio su GitHub si fa con il pulsante "Save to GitHub" della piattaforma: l'agente non può caricare il codice da solo sull'account della titolare.
- Siccome il repository è pubblico, password, chiavi e file di credenziali non vengono inclusi. Per far funzionare il codice altrove, chi lo scarica deve impostare i propri valori.
- Il nome del repository lo sceglie la titolare al momento del salvataggio.
- Le iscrizioni all'evento, i contatti del quiz e le statistiche restano nel database del sito e non finiscono su GitHub.
- Il cambio della password admin (fase 2) è consigliato ma non indispensabile per il salvataggio.
